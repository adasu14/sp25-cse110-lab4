3. Variables declared with var are scoped to the entire function, even if they are declared inside blocks like if or for. This can cause bugs when developers expect block scoping. var declarations are hoisted to the top of their function, meaning the variable exists before the line it's defined on. This can lead to confusing bugs with undefined values.
